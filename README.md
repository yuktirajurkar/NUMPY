# NumPy Arrays and Operations

This repository contains Jupyter Notebooks covering fundamental NumPy concepts, including array creation, indexing, slicing, and common array operations. It is intended for beginners learning numerical computing with Python and serves as a practical reference for understanding NumPy arrays.

## Repository Structure

| File | Description |
|--------|------------|
| `numpy_arrays.ipynb` | Introduction to NumPy arrays, creation methods, indexing, and slicing techniques. |
| `array_indexing.ipynb` | Practice notebook focused on array indexing and accessing elements. |
| `array_operations.ipynb` | Demonstrates various array operations such as arithmetic, aggregation, and manipulation. |
| `exersises.ipynb` | Collection of NumPy exercises to reinforce concepts learned in previous notebooks. |

## Topics Covered

- Introduction to NumPy
- Creating NumPy Arrays
- Array Attributes
- Indexing Arrays
- Array Slicing
- Multi-dimensional Arrays
- Arithmetic Operations
- Statistical Operations
- Array Manipulation
- Practical Exercises
